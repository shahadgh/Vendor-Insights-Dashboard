# Vendor-Insights-Dashboard
This analysis is about tracking employee spending across different vendors over time. It helps a company or team understand how much employees are spending, which vendors are used most frequently, and how spending patterns change over time.

# Insights the Dashboard Brings:

- Top vendors and employee spending habits.

- Total spend vs. budget to monitor overspending.

- Trends over time (daily and monthly) to spot irregularities or seasonal patterns.

- Manager-level summaries for decision-making or expense approval oversight.
